# RR Technologies — Corporate Landing Page

A modern, fully responsive corporate landing page built with pure HTML and CSS.  
No frameworks, no JS — just clean, maintainable code that works everywhere.  

Designed to showcase advanced CSS techniques: dark/light theme switching, CSS-only animations, custom properties, and a working contact form via Formspree.  
Ready for any CMS or backend integration.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup  
- **CSS3** – Flexbox, Grid, CSS Variables  
- **CSS-only theme toggle** – dark/light mode via `:has()`  
- **CSS animations** – hover effects, pulse, smooth transitions  
- **Responsive design** – desktop-first approach  
- **Formspree** – functional contact form without backend  
- **Google Fonts & Fontshare** – modern typography  

---

## ✨ Key Highlights

- ✅ **Dark/light theme toggle** – pure CSS, no JavaScript needed.  
- 🎬 **CSS animations** – smooth hover on buttons, cards, forms, and nav links.  
- 📱 **Fully responsive** – looks great on every screen, from mobile to 4K.  
- 📬 **Working contact form** – connected to Formspree, ready to receive submissions.  
- 🧼 **Clean, maintainable CSS** – BEM-inspired naming, reusable variables.  
- 🍔 **CSS-only mobile menu** – burger navigation works without JS.  
- ⚡ **No frameworks, no bloat** – just solid HTML and CSS.
